# Country Search — проектные решения

## 1. Отмена устаревших запросов

Цепочка на каждое изменение ввода:

`input` → `current?.abort()` → новый `AbortController` → `search(query, signal)` →
`fetch(url, { signal: AbortSignal.any([signal, AbortSignal.timeout(ms)]) })`

Почему именно `abort()`, а не флаг «актуальный ли этот ответ»:

- при флаге запрос всё равно уходит на сервер и возвращается, тратя трафик,
  соединение и время сети; гонка не устраняется, а только маскируется на экране;
- ответ успевает прийти и отрисоваться **между** двумя вводами: пока debounce
  ждёт 300 мс, старый промис уже разрешён, и флаг придётся проверять ещё и в
  момент отрисовки, то есть в двух местах вместо одного;
- `AbortController` освобождает ресурсы сразу: в DevTools такие запросы видны
  как `(canceled)`, сервер получает разрыв.

Почему `abort()` вызывается на каждый ввод, а не внутри debounce-функции:

если отменять только в момент старта нового запроса, между вводом и этим
моментом проходит `DEBOUNCE_MS`. Всё это окно старый ответ ещё жив и может
отрисоваться под уже новым текстом. Поэтому отмена стоит в `input()` до
`scheduleSearch(...)`.

Почему в отложенной функции есть проверка `if (controller.signal.aborted) return;`:

пока тикает таймер debounce, пользователь мог стереть поле (`input('')`).
Контроллер к этому моменту уже отменён, и запрос отправлять не нужно.
Без этой проверки очистка поля не отменяет запрос, который стоит в очереди
таймера.

Почему `AbortError` не показывается как ошибка:

отмена — это наше собственное решение, а не сбой сервера. `classifyError`
возвращает для неё `'cancelled'`, и контроллер в этой ветке не меняет состояние
вовсе. Таймаут приходит как `DOMException` с `name === 'TimeoutError'` и
обрабатывается отдельно: пользователю показывается ошибка с кнопкой повтора,
потому что «сервер молчит» — это настоящая проблема, в отличие от отмены.

## 2. Задержка debounce

Выбрано `DEBOUNCE_MS = 300` (`src/constants.ts`).

- Средний интервал между нажатиями при наборе — 150–250 мс, поэтому 300 мс
  схлопывает набор целого слова в один запрос и остаётся незаметной для глаз.
- Без debounce запрос уходил бы на каждую букву: `spain` — пять запросов вместо
  одного, лишний трафик и риск упереться в лимит API (у `countries.dev` —
  около 60 запросов в секунду на IP), а список мерцал бы.
- При 1000 мс и больше интерфейс «залипает»: пользователь печатает и не видит
  реакции, начинает стирать и набирать заново — число запросов не падает,
  а растёт.

## 3. Сложность

`mapCountryResponse` — `O(L + C + B)`, где `L` — число языков, `C` — валют,
`B` — границ: три линейные проходки по массивам ответа, остальные поля —
доступ за `O(1)`. Память — `O(L + C + B)` на новые массивы (вход не мутируется).
От числа стран сложность не зависит: один вызов обрабатывает одну страну,
массив обрабатывается снаружи через `.map`.

`classifyError` — `O(1)`: `instanceof` и сравнение строки `name`.

`debounce` — `O(1)` на вызов, память `O(1)` на одну обёртку.

## 4. Чистый код

| Принцип                             | Где                                                                                                                                                     |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Единственная ответственность        | `classifyError` только классифицирует, `mapCountryResponse` только маппит, `ui.ts` только строит DOM, `searchController.ts` только управляет состоянием |
| Чистые функции                      | `debounce`, `mapCountryResponse`, `classifyError` — без побочных эффектов и без обращений к сети/DOM                                                    |
| Инверсия зависимостей               | `createSearchController({ search, onState, debounceMs })`: тесты подставляют свою `search`, `main.ts` — настоящую                                       |
| Логика отделена от DOM              | `searchController.ts` не импортирует ничего из DOM; `ui.ts` не знает про `fetch`                                                                        |
| Явные контракты                     | `types.ts`: `CountryRaw`, `CountryCard`, `SearchState` с дискриминантом `kind`                                                                          |
| Без магических чисел                | `constants.ts`: `DEBOUNCE_MS`, `DEFAULT_TIMEOUT_MS`, `API_BASE_URL`                                                                                     |
| Без `innerHTML`                     | `ui.ts` строит всё через `createElement` / `textContent` / `replaceChildren`                                                                            |
| Обработка ошибок отдельно от потока | `try/catch` только в `run`, разбор причины — в `classifyError`                                                                                          |
